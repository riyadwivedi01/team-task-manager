# 🧑‍💼 Team Task Manager

A full-stack web application that allows teams to manage projects, assign tasks, and track progress with role-based access (Admin & Member).

---

## 🚀 Features

* 🔐 Authentication (Signup/Login)
* 👨‍💼 Role-Based Access (Admin & Member)
* 📋 Task Creation & Assignment
* 📊 Task Status Tracking (Pending / Completed)
* 📌 Dashboard for tasks overview

---

## 🛠 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MongoDB

---

## ⚙️ Installation (Local Setup)

1. Clone the repository

```bash
git clone https://github.com/riyadwivedi01/team-task-manager.git
```

2. Go to project folder

```bash
cd team-task-manager
```

3. Install dependencies

```bash
npm install
```

4. Start server

```bash
npm start
```
